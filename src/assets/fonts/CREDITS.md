# Locally Served Fonts

Inter and Cormorant Garamond, normal variable weight, Latin and Latin Extended
subsets. Font bytes are unmodified Fontsource 5.3.0 assets; CSS family names match
WineSnap's existing typography. No font registry, CDN or Google Fonts request is
made at runtime. Other scripts/languages fall back to the existing system stack.

Archive SHA-512 integrity was checked before copying the four selected WOFF2 files;
`provenance.json` records pinned public sources and per-file SHA-256 checksums.
No font package scripts were installed or executed, and no runtime dependency
was added.
